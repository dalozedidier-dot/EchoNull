EchoNull 64-updates pack (release-ready v0.1.2)

How to apply

1) Unzip at repository root (overwrite files).
2) Remove old top-level packages from the distribution (do not delete them locally if you still use them):
   - packaging now installs only src/echonull.*
3) Commit and push.
4) Check GitHub Actions:
   - CI workflow builds wheel and runs smoke install
   - extended-tests and sweep still work

Local checks

- make install
- make lint
- make test
- make build
